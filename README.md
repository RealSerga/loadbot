# Telegram бот для мониторинга сети

Простой бот на Python, который держит в канале одно сообщение и постоянно редактирует его, показывая текущее время и скорость загрузки/выгрузки выбранного сетевого интерфейса.

## Настройка

1. Создайте Telegram-бота у [@BotFather](https://t.me/BotFather) и добавьте его администратором в нужный канал с правом редактировать сообщения.
2. Заполните `settings.py` (значения можно также передавать через переменные окружения):
   - `BOT_TOKEN` — токен бота;
   - `CHANNEL_ID` — ID канала (`-100...` или `@username`);
   - `INTERFACE` — имя интерфейса (опционально, без него выберется первый активный не-loopback);
   - `UPDATE_INTERVAL` — период обновления в секундах (по умолчанию 5);
   - `MESSAGE_ID` — если нужно редактировать уже существующее сообщение.
3. Установите зависимости и виртуальное окружение через `uv` и `pyproject.toml`:
   ```bash
   uv venv .venv
   source .venv/bin/activate
   uv sync
   ```

## Запуск

```bash
uv run bot.py
```

`uv run` подтянет зависимости из `pyproject.toml` и запустит файл в вашем окружении.

Секреты можно передать через окружение, не записывая их в `settings.py`, например:  
`BOT_TOKEN=xxx CHANNEL_ID=-100... uv run bot.py`.

Бот отправит (или начнет редактировать) одно сообщение в канале и будет обновлять его каждые `UPDATE_INTERVAL` секунд. В сообщении отображаются:
- текущее время;
- выбранный интерфейс;
- мгновенная скорость Upload/Download;
- суммарный трафик, отправленный и полученный интерфейсом.

Если Telegram временно ограничит частоту запросов, бот подождет и продолжит работу.
